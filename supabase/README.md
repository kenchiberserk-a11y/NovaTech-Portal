# Configuración de Supabase

1. Crea un proyecto dedicado para desarrollo y pruebas.
2. Ejecuta `schema.sql` desde SQL Editor.
3. Crea usuarios desde Authentication; los perfiles nuevos tienen rol `employee` por defecto.
4. Asigna el rol `admin` únicamente mediante un procedimiento administrativo confiable.
5. Mantén separados los proyectos de prueba y producción. No guardes claves privadas ni contraseñas en Git.
